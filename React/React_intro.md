# React

React is a JavaScript library for building user interfaces. It allows developers to create reusable UI components and manage the state of their applications efficiently. React uses a virtual DOM to optimize rendering and improve performance.

#### Imagine tumhe ek website banani hai jisme:
- Navbar
- User profile card
- Product card
- Footer

Vanilla JavaScript mein tum HTML elements create kar sakte ho, unhe DOM mein add kar sakte ho aur unka content update kar sakte ho.

React mein hum website ko chhote-chhote reusable parts mein divide kar dete hain. In parts ko Components kehte hain.

For example:
- Navbar = Component
- UserCard = Component
- Footer = Component

Aur in sabko combine karke hum complete website bana sakte hain.

Simple definition:

React is a JavaScript library used to build user interfaces using reusable components.
