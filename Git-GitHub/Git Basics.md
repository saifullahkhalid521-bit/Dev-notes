## Git commands

1. git init: Initialize a new Git  repository in the current folder.

2. git status: Check the status of files (modified, staged, untracked).

3. git add filename / git add .: Add files to staging area. Use '.' to add all files.

4. git commit -m 'message': Save changes as a snapshot with a message.

5. git log: View commit history.

6. git remote add origin URL: Connect local repository to a remote repository.

7. git push -u origin main: Upload local commits to remote repository.

8. git clone URL: Download a repository from remote.

9. git pull: Fetch and merge latest changes from remote.

10. git branch: List all branches.

11. git checkout -b branch-name: Create and switch to a new branch.

12. git merge branch-name: Merge a branch into current branch.

13. cd folder-name: Navigate into a folder.

14. cd ..: Go one directory up.

15. ls: List files and folders.

16. pwd: Show current directory path.

17. mkdir folder-name: Create a new folder.

18. touch file.txt: Create a new file.
